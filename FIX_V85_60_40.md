# V85.60.45 – MOBILE OPS + NOTIFICATION SYNC ROBUST FIX

- Mobile operational updates now require a returned Cloud row; an RLS-filtered/zero-row UPDATE is treated as failure and queued for retry.
- Mobile flushes pending operational changes when entering Vận hành and after saving.
- Notification screen reports pending sync failures instead of silently ignoring them.
- Existing PC ↔ Mobile ↔ Supabase notification sync_key/security model is preserved.
- Existing signer, MLL/KPI, icons, Desktop shortcut and V85.60.39 data-wipe lock fix are preserved.


## V85.60.44 – Cloud timeout/read robustness
- Supabase REST timeout increased from 15s to 60s.
- GET/HEAD/PATCH/PUT/DELETE transient network timeout/URL errors retry up to 3 attempts with backoff.
- POST/INSERT is not auto-retried at request level to avoid duplicate records.
- Fixes false `Lỗi đồng bộ tạm thời` caused by `The read operation timed out`.
